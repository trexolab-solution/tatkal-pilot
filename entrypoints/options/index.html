    Retry & timing

    When IRCTC shows "High Load", TatkalPilot presses the button again like you would. These apply to every booking. Retrying faster than 1 second apart can get your account throttled, so values are limited.

    Download

    This extension is not on the Chrome Web Store, so it checks GitHub once a day for a newer release. Nothing is installed for you: download the zip, unzip it over the old folder, then press Reload on chrome://extensions.
